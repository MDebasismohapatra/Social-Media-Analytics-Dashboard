# Social-Media-Analytics-Dashboard
An interactive Social Media Analytics Dashboard built using Microsoft Power BI to analyze engagement, reach, impressions, audience sentiment, platform performance, and campaign effectiveness through interactive visualizations and DAX measures.
# Social Media Analytics Dashboard | Power BI

## Project Overview
The dashboard transforms social media metrics into meaningful visual insights, making it easier to compare platforms, identify high-performing posts, evaluate campaigns, and monitor performance trends.
This project demonstrates the practical application of data visualization, DAX calculations, interactive filtering, and dashboard design for business analysis.

## Objectives
* Analyze social media reach, impressions, and engagement.
* Compare performance across different social media platforms.
* Identify top-performing posts and content types.
* Understand audience engagement across age groups and genders.
* Analyze audience sentiment and campaign effectiveness.
* Track engagement and impression trends over time.
* Enable interactive exploration of data through filters and drill-through functionality.

## Dashboard Features
### 1. Executive Overview
Provides a high-level summary of social media performance through KPI cards, platform comparisons, geographical analysis, sentiment distribution, and monthly performance trends.

### 2. Platform Performance
Compares social media platforms based on reach, impressions, engagement, engagement rate, and click-through rate.

### 3. Top Performing Posts
Highlights posts based on engagement and provides a detailed view of post-level metrics, including platform, campaign, content type, reach, impressions, and sentiment.

### 4. Post Details
Presents selected post information and associated performance metrics to support more detailed analysis.

### 5. Audience & Sentiment
Analyzes audience engagement by age group, gender, and platform while examining the distribution of audience sentiment.

### 6. Campaign & Content Strategy
Evaluates campaign performance and compares content types using engagement, impressions, sentiment, and engagement-rate metrics.

### 7. Trend Analysis
Visualizes engagement and impression trends across monthly and weekly periods to help identify changes in social media performance.

### 8. Post Details — Drill-Through
Provides a more detailed view of individual posts, including likes, comments, shares, clicks, reach, impressions, and engagement rate.

## Key Performance Indicators (KPIs)
The dashboard includes metrics such as:
* Total Reach
* Total Impressions
* Total Engagement
* Engagement Rate
* Total Posts
* Click-Through Rate
* Likes, Comments, Shares, and Clicks

## How to Use the Project
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop if it is not already installed.
3. Open the `.pbix` project file in Power BI Desktop.
4. If Power BI requests access to the original data source, configure the appropriate data source or file path.
5. Refresh the data if the required source is available.
6. Navigate through the report pages and use the slicers and interactive visuals to explore the results.
